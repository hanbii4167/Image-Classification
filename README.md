# 🔄 재활용품 이미지 분류 프로젝트 (VGG19 기반)

## 📖 개요
이 프로젝트는 **VGG19 모델을 활용한 재활용품 이미지 분류**를 수행하는 연구입니다.
플라스틱, 유리, 종이 등의 다양한 재활용품 이미지를 분석하고 분류하는 인공지능 모델을 개발하여, 자원 관리 및 환경 보호에 기여하는 것이 목표입니다.

> **🎯 연구 및 대학원 입시 대비:**
> 본 프로젝트는 **딥러닝을 활용한 이미지 분류 모델 연구**로서, 환경 문제 해결을 위한 AI 응용 사례를 제공합니다.
> 영상 데이터 전처리부터 CNN 기반 모델 학습까지의 과정을 익히고, 논문 작성 및 실무 프로젝트에 적용할 수 있습니다.

## 🛠 사용된 라이브러리 및 기술
- `OpenCV` : 영상 데이터 전처리
- `TensorFlow` / `PyTorch` : 딥러닝 모델 학습 및 평가
- `NumPy`, `Pandas` : 데이터 처리 및 분석
- `Matplotlib`, `Seaborn` : 데이터 시각화

## 🔬 사용된 모델: **VGG19**
- VGG19는 깊이가 깊은 CNN 모델로, 이미지 분류에서 높은 성능을 보이는 대표적인 신경망입니다.
- 주요 특징:
  - 19개의 층을 가진 깊은 구조
  - 작은 3x3 컨볼루션 필터 사용
  - 전이 학습(Pre-trained Model) 적용 가능
  - 높은 분류 성능과 강력한 표현력

## 📂 분석 대상 및 실험 내용
- **재활용품 이미지 데이터셋 구축**
- **각 재활용품(플라스틱, 유리, 종이 등)의 시각적 특징 학습**
- **VGG19 모델을 활용한 자동 분류**
- **정확도 평가 및 모델 최적화**

## 🚀 프로젝트 목표
- **재활용품 자동 분류 모델 개발**: 환경 보호 및 자원 관리에 AI 활용
- **CNN 기반 이미지 분류 기술 학습**: 모델 설계 및 최적화 과정 익히기
- **데이터 기반 연구 수행**: 논문 작성 및 실험을 위한 데이터셋 구축
